# Homebrew tap for OpenSource

Install [OpenSource](https://github.com/mohnish/opensource), a command-line tool
that adds an open source license to your project, as a Homebrew cask.

The cask installs a prebuilt, signed and notarized macOS binary for Apple
Silicon or Intel. Go is not required.

## Installation

After the first stable binary release has published `Casks/opensource.rb` to
this repository, install with:

```bash
brew install --cask mohnish/opensource/opensource
```

Check the installed version and save your name and email:

```bash
opensource --version
opensource --setup
```

Then, from your project directory, generate a license:

```bash
opensource --license mit
```

See the [OpenSource README](https://github.com/mohnish/opensource#usage) for
supported licenses and more examples.

## Upgrade

```bash
brew update
brew upgrade --cask mohnish/opensource/opensource
```

## Uninstall

```bash
brew uninstall --cask opensource
```

Your saved name and email in `~/.osrc` are retained.

## Moving from the Homebrew formula

If you previously installed OpenSource as a formula, remove it before
installing the cask:

```bash
brew uninstall --formula opensource
brew install --cask mohnish/opensource/opensource
```

## Maintenance

The [OpenSource release workflow](https://github.com/mohnish/opensource/actions/workflows/release.yml)
generates and updates `Casks/opensource.rb` on stable releases using
GoReleaser. It publishes the binaries and SHA-256 checksums as
[GitHub Release assets](https://github.com/mohnish/opensource/releases), then
audits, installs, and smoke-tests the published cask on macOS. Prereleases do
not update this tap.

Keep `main` available for automated cask updates. Configure release secrets in
`mohnish/opensource`; `HOMEBREW_TAP_TOKEN` needs Contents read and write access
to this tap repository. See the
[release instructions](https://github.com/mohnish/opensource#releasing) for
setup and publishing steps.

The cask and its checksums are generated by the release workflow. Do not edit
them manually or commit binaries to this repository.

Report issues in the [OpenSource issue tracker](https://github.com/mohnish/opensource/issues).
